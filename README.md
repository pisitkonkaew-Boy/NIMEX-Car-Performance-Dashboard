# NIMEX Car Performance Dashboard

หน้าเว็บ Dashboard ที่อ่านข้อมูลจาก Google Sheet ผ่าน Apps Script

- ข้อมูลทั้งหมดอยู่ใน Google Sheet ไม่มีตัวเลขใน repo นี้ ห้ามนำ fleet-seed.json หรือรายงานต้นฉบับขึ้น repo
- ผู้ชมทั่วไปเปิดหน้าเว็บตามปกติ ผู้ดูแลเปิดด้วย `#admin` ต่อท้ายลิงก์แล้วใส่รหัส
- รหัสผู้ดูแลเก็บใน Script Properties ชื่อ `ADMIN_KEY` ของ Apps Script เท่านั้น
- ที่อยู่ระบบข้อมูลตั้งไว้ใน `config.js`
